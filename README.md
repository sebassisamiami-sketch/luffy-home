# Luffy Home

Pantalla de inicio estilo Apple TV para Android TV y Google TV (cualquier marca).

## Descargar
- **En el TV con Downloader:** escribe el código **7485713** (o abre aftv.news/7485713).
- **Página:** https://sebassisamiami-sketch.github.io/luffy-home/
- **APK directos (última versión):**
  - Completa (Android 7+): [LuffyHome.apk](https://github.com/sebassisamiami-sketch/luffy-home/releases/latest/download/LuffyHome.apk)
  - Lite (Android 5–6 o poca memoria): [LuffyHomeLite.apk](https://github.com/sebassisamiami-sketch/luffy-home/releases/latest/download/LuffyHomeLite.apk)
